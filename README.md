# 鸿笺 · 华为 PC 营销软文智能体

「AI+华为PC营销软文智能体」赛题作品，自研 Agent。

给门店销售员用的软文工具：打开就有今天该写什么，点一下出稿，一次给三种不同写法，挑一篇改几个字就能发。

**ima 在这个作品里只提供产品事实和图片。** 场景理解、平台策略、系统提示词、图文编排、事实核验、图片核验、合规拦截、改稿和导出，全部由鸿笺自己的 Agent 完成。

## 三个针对业务痛点设计的功能

**1. 今日创作台（解决"销售员不愿意写"）**
打开页面就是四张推荐卡片，按日期和节点挑好今天值得写的选题。不用填任何表单，点「一键写这篇」直接出稿。

**2. 一题三解（解决"千篇一律"）**
同一个任务，系统用三种人设各写一篇：柜哥导购（直接讲卖点）、学长学姐（口语、敢说缺点）、隔壁同事（少提参数多提场景）。三篇的标题、切入点、语气、卖点顺序都不同，挑一篇顺眼的。检索和核验只跑一次，三篇总耗时约 0.4 秒。

**3. 新品事实卡（解决"大模型对新品幻觉"）**
生成之前，先把这台机器「能说的」「不能说的」「资料未确认的」「可引用的价格」摆到桌面上。Agent 只能从「能说的」里取料，不允许自由发挥。

## 怎么试

页面上有三种用法。

1. **今日创作台**：打开就是推荐，点「一键写这篇」。
2. **自然语言直接说**：在「工作台」输入框写「给 MateBook Pro 写一篇开学季小红书，面向大学新生」，按 Enter 或点「生成稿件」。
3. **结构化指定**：产品、场景、平台、受众、主卖点、是否写价格，六个字段任意填。

信息不全就追问：输入「想买轻薄本」会返回追问卡；输入「MateBook 14 写篇公众号」会因为机型有歧义追问是鸿蒙版还是酷睿 Ultra——不自动替你选。

生成后的「稿件」分四段：场景判断、知识库依据、图文软文、核验结果。点正文任意一句，右侧「证据」面板显示这句话依据的事实原文、资料标题、知识库路径、官方链接和核验日期。「策略对比」可以并排比较两次运行，「修改台」支持「换成朋友圈」「主卖点换成续航」「删掉价格」这类自然语言指令。右上角是知识库状态：账号掩码、知识库名称、连接状态、接口返回和检索记录。右上角「运行档案与自测」页可以一键跑 21 条内置用例。

## 覆盖范围

- **8 个场景**：开学季、职场办公、内容创作、家庭换新、企业采购、门店到访、新品首发、节日营销。
- **4 个平台**：公众号、小红书、门店朋友圈、门店海报。
- **10 个机型**：MateBook Pro / Pro S / 14 鸿蒙版 / 14 酷睿 Ultra / Fold 非凡大师 / D 14 / D 16 / D 16 SE / GT 14 / X Pro。
- **4 种写稿人设**：柜哥导购、学长学姐、隔壁同事、严选买手。
- **2 种文案引擎**：配置 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL` 时用公开大模型（只允许引用给定的事实 id 和图片 id）；未配置时用确定性编排器，全链路照样可用。

## 三段式设计

场景解析 → 平台策略 → ima 资料与图片检索 → 事实点提取 → 图文编排 → 软文生成 → 事实核验 → 图片核验 → 合规检查 → 导出。

| 赛题模块 | 实现位置 |
|---|---|
| 账号与知识库 | `app/kb/store.py` |
| 任务输入与追问 | `app/agent/understand.py`、`converse.py`（对话式挖掘） |
| 知识与图片检索 | `app/kb/ima_client.py` + `app/agent/retrieve.py` |
| 场景与平台策略 | `app/agent/profiles.py` + `strategy.py` |
| 图文软文生成 | `app/agent/prompts.py` + `compose.py` |
| 事实核验 | `app/agent/verify.py` |
| 合规检查 | `app/agent/compliance.py` |
| 修改与导出 | `app/agent/pipeline.py` + `export.py` |
| 评测自测 | `app/agent/selftest.py`（21 条用例） |

## 三条硬约束

- **事实只能来自知识库**。参数、功能、价格、卖点都必须能追溯到具体知识条目；出现证据之外的数字或型号，会被删除并记入待确认信息。
- **图片必须来自知识库且与机型匹配**。每张图都带图片名、来源、插入位置和说明；型号不符的图会被移除，配额不足时提示而不是借用别的机型的图。
- **编造的都会被拦住**。价格、补贴、库存、销量、奖项、用户评价，知识库里没有就不写；「写个国补立减2000」「全网最低价」「写一段我用了一年的体验」会被拒绝并说明原因。
