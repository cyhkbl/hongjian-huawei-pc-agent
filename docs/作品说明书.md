# 鸿笺 · 华为 PC 营销软文智能体｜作品说明书

> 赛题：AI+华为PC营销软文智能体
> 仓库：https://github.com/cyhkbl/hongjian-huawei-pc-agent
> 在线演示（魔搭创空间，公开）：https://modelscope.cn/studios/cyhkbl/hongjian
> 本地运行：`python -m app.main`，打开 http://127.0.0.1:7860

部署形态：Docker 类型创空间，监听 `0.0.0.0:7860`。镜像内置知识库快照（`kb_snapshot/`，32 MB，含 P1—P8 的资料文本与 112 张图片的索引及文件），因此评审期打开公网地址即可直接生成，不依赖外部服务。仓库里的 `.gitignore` 排除了 `kb_snapshot/`、`.env`、`runs/` 和 `.kb_cache/`，GitHub 上不出现知识库原文和凭证。

## 一、作品是什么

输入产品、人群、场景和渠道，鸿笺生成一份带知识库依据的图文软文，并逐句核验事实、逐图核验型号、逐条检查合规。

ima 在这个作品里只做一件事：提供产品事实和图片。场景理解、平台策略、系统提示词、图文编排、事实核验、图片核验、合规拦截、改稿和导出,全部由我们自研的 Agent 完成。

```
任务输入 → 场景解析 → 平台策略 → ima 资料与图片检索 → 事实点提取 → 图文编排
        → 软文生成 → 事实核验 → 图片核验 → 合规检查 → 导出
```

十个功能模块对应的实现：

| 赛题模块 | 实现位置 |
|---|---|
| 账号与知识库 | `app/kb/store.py` 的 `status()`；界面右上角“账号与知识库”抽屉 |
| 任务输入与追问 | `app/agent/understand.py` |
| 知识与图片检索 | `app/kb/ima_client.py` + `app/agent/retrieve.py` |
| 场景与平台策略 | `app/agent/profiles.py` + `strategy.py` |
| 图文软文生成 | `app/agent/prompts.py` + `compose.py` |
| 事实核验 | `app/agent/verify.py` 的 `check_facts` |
| 合规检查 | `app/agent/compliance.py` |
| 修改与导出 | `app/agent/pipeline.py` 的 `revise()` + `export.py` |
| 评测自测 | `app/agent/selftest.py`（21 条用例，页面“档案与自测台”可一键跑） |

## 二、核心链路怎么走

以“给 MateBook Pro 写一篇开学季小红书，面向大学新生”为例：

1. **场景解析**。`understand.parse_task` 从自然语言里取出机型、平台、场景、受众；机型是系列名且有歧义时（“MateBook 14”同时有鸿蒙版和酷睿 Ultra，“D 16”与“D 16 SE”相近），不自动挑选，而是返回带差异说明的追问。
2. **平台策略**。`profiles` 给出这个场景下的人群、痛点、购买阶段、内容目标、开场切入方式、卖点权重、配图偏好、语气、篇幅、CTA 风格和禁忌。小红书的口径是 3–6 张图、口语、短段、可收藏；公众号是 2–4 张图、1200–2200 字、分节叙事。
3. **检索取证**。`retrieve.gather` 先调 `search_knowledge`（本地镜像模式走本地索引，ima 模式走真接口），再按场景标签挑 8–14 条事实、同型号图片和可引用的价格记录。检索过程写入 `EvidencePack.trace`，界面第二段“知识库依据”逐条列出事实编号、资料标题、KB 路径、官方链接和核验日期。
4. **图文编排**。卖点按“场景权重 × 机型加成 × 平台微调”打分排序。开学季排第一位的是便携，职场办公会换成办公效率，内容创作换成屏幕和性能。`Strategy.rationale` 会把每个决定写成可读的理由，包括舍弃了哪些卖点、为什么。
5. **生成**。配置了公开 LLM 时走 `llm.py`：系统提示词限定只能引用给定的事实 id 和图片 id，输出 JSON；引用了清单外的 id、JSON 解析失败、超时或限流都会自动降级到确定性编排器，并在结果里标注原因。没有配 LLM 时直接用编排器，全链路可用。每篇成稿的每个含产品断言的段落都带 `fact_ids`。
6. **事实核验**。逐句对照它引用的事实：出现知识库以外的数字、型号或功能名，删除或降级成原事实的带限定表述；跨型号拼接直接删除并在“待确认信息”里说明。限定条件（典型值、柔光版、约、随配置变化、需 SKU 核对）不随段复读，统一进文末“使用前请注意”。
7. **图片核验**。检查每张图是否在知识库里、型号是否与稿件机型一致、来源 URL 和页面是否齐全、文件能否解码、颜色是否与文中提到的颜色冲突、数量是否超出平台上限。小红书要 3 张而机型只有 2 张时如实提示图片不足，不借别的型号的图。
8. **合规检查**。规则引擎逐条扫描：绝对化用语、虚假承诺、价格误导、无依据对比、贬低竞品、虚构亲身体验、动态信息（国补、补贴、限时、库存、赠品）、虚假稀缺、平台硬规则。命中就改写或拦截，规则名和改写前后都显示。
9. **导出和改稿**。`revise()` 支持“换成朋友圈”“主卖点换成续航”“删掉价格”“再短一点”这类自然语言指令，改完重跑全链路并重新核验，版本链可回看。导出 md / txt / html / docx / json，门店海报在页面渲染成成品并可导出 PNG，主视觉保持原比例。

## 三、知识库调用

`app/kb/` 是知识层的全部接口，上层不关心数据来自哪里。同一个 `KnowledgeBase` 协议下有三条路径：

**ima 模式**按官方 OpenAPI 调用四个接口，是赛题的主路径：

| 步骤 | 接口 | 用途 |
|---|---|---|
| A | `search_knowledge_base` | 按名称找共享知识库，取 `kb_id` |
| B | `get_knowledge_list` | 浏览目录，搜索为空时回退 |
| C | `search_knowledge` | 按型号和任务搜索资料 |
| D | `get_media_info` | 取原文或图片的访问链接 |

联调记录（用真实凭证跑过）：`search_knowledge_base` 正常返回「任德耀新建华为PC知识库」；`get_knowledge_list` 的真实返回是根目录只有一项与知识库同名的包装文件夹（`media_type: 99`），它的 `media_id` 才是真正的根 `folder_id`，不带 `folder_id` 调用只能拿到这一项。这个字段官方文档没写，代码里按实测结果处理（`app/kb/vfs.py` 的 `_entry_from_item` 与 `_root_folders`）。目录树 289 个文件夹、结构与本地副本一致，342 个型号目录、图片索引和价格快照都能解析。

还发现 ima 有**每日资料获取次数上限**（错误码 220021）。用尽后 `ima 不可达（资料获取次数已达上限）`，系统自动降级到本地镜像，不会伪造返回值。客户端为此做了请求间隔节流，`110021` 频控用线性退避，目录遍历带磁盘缓存。

**本地镜像模式**读取主办方提供的知识库副本。线上创空间用的就是这条路径：镜像里放了 `kb_snapshot/`，评审期打开地址即可生成，不依赖外部服务。

ima 配了但连不上时，状态面板会写“ima 不可达（具体原因），已降级为本地镜像”，不会拿本地数据冒充 ima 返回。

页面右上角的“账号与知识库”抽屉显示：当前账号掩码、知识库名称、连接状态灯、当前模式、最近一次接口返回、检索 trace 列表、型号/事实/图片/价格计数、重新连接按钮。全程不显示完整凭证。

## 四、系统提示词

完整提示词在 `app/agent/prompts.py`，页面“档案与自测台”可读全文（版本号 `hj-prompt-2026.10.18-r1`）。赛题要求的八个模块都在：

1. **角色与任务**：服务于华为 PC 营销，交付有知识库依据的图文软文。
2. **场景理解**：提取目标人群、使用场景、购买阶段、主要问题和内容目标。
3. **平台规则**：按公众号、小红书、朋友圈、海报决定标题、篇幅、结构、语气和行动引导。
4. **知识库约束**：型号、参数、功能、价格、卖点只能来自指定知识库。
5. **图片规则**：图片必须来自知识库，核对产品型号，输出来源、说明和建议插入位置。
6. **生成要求**：输出标题、导语、正文、配图方案、行动引导和平台标签。
7. **核验规则**：无法确认的信息不得生成；资料冲突时停止输出并提示人工确认。
8. **合规规则**：禁止绝对化宣传、虚假承诺、无依据对比、价格误导和竞品贬低。

另外加了：输出 JSON schema、封闭的事实/图片 id 清单、冲突停止规则、反套话词表（禁“震撼”“颠覆”“全能”“赋能”之类）、few-shot 示例。

## 五、运行结果

`docs/samples/` 有 8 份完整成稿，覆盖 5 个机型、8 个场景和全部 4 个平台。每份都带四段结构（场景判断、知识库依据、图文软文、核验结果）和图片清单。

内置评测集 21 条用例全部通过，对应赛题的几类测试：

| 用例组 | 覆盖内容 |
|---|---|
| 统一测试 | 基础生成、换场景（切入点/卖点顺序/配图计划必须变）、换平台（结构/语气/图数/CTA 必须变） |
| 追问与混淆 | “MateBook 14”鸿蒙版与酷睿 Ultra 追问、“想买轻薄本”追问用途、D 16 与 D 16 SE 不混用、Pro 与 Pro S 区分 |
| 拒绝编造 | 写国补立减、全网最低价、永久保价、亲身体验、贬低竞品、销量和获奖 |
| 改稿 | 删价格、换平台、换主卖点后重新核验 |
| 价格守卫 | 只给系列名、起价当全系价、已下架商品、要求编价、绝对化促销、价格写进标题 |
| 规格表述 | “最高 20 W”“最大 66 W”这类规格上限不误判为绝对化宣传 |

用 10 个机型 × 8 场景 × 4 平台生成 320 篇，0 篇跨型号事实或图片，0 篇颜色混用，每篇都有“限制”段，320 篇文本互不相同。

## 六、部署

**本地**：`pip install -r requirements.txt`，复制 `.env.example` 为 `.env`，填 ima 凭证，`python -m app.main`，打开 http://127.0.0.1:7860。

**魔搭创空间（已部署，公开）**：https://modelscope.cn/studios/cyhkbl/hongjian

Docker 类型，服务监听 `0.0.0.0:7860`，镜像内置知识库快照。部署后实测：`/api/health`、`/`、`/api/kb/status` 均 200；知识库载入 10 个型号、1261 条事实、68 张图片、141 条价格；生成一篇小红书返回 5 张图片，图片接口真实返回 JPEG 字节；追问流程返回 4 个问题；导出 md / json 正常；Playwright 连续跑完首页、生成、点句出证据、知识库抽屉、追问卡、海报、自测台、窄屏八步，应用自身无控制台报错。

需要切换成实时 ima 时，在创空间密文管理里加 `IMA_OPENAPI_CLIENTID`、`IMA_OPENAPI_APIKEY`，把 `KB_MODE` 改成 `ima`，重新部署即可。当前未配，所以线上跑本地镜像（界面如实标注模式，没有伪装成 ima 返回）。需要 LLM 再加 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。详细步骤见 `DEPLOY_CN.md`。

安全：GitHub 仓库不含任何 API Key、Client ID 或知识库原文，推送前跑过凭证扫描和 `git ls-files` 知识库泄漏扫描；`.env`、`runs/`、`.kb_cache/`、`kb_snapshot/` 都在 `.gitignore` 里；所有接口只返回凭证掩码；测试用假 key 扫描全部响应确认不泄露。公开演示服务做了请求体大小限制和按 IP 限速。知识库快照只随镜像分发，不进源码仓库——这一点是主办方“不得对外传播资料”的要求。

## 七、已知限制

- **ima 有每日资料获取次数上限（220021）**。联调当天把配额用尽后，ima 模式自动降级为本地镜像并在状态面板写明原因。之后要切回 ima，需要等配额重置或换账号。
- **本地镜像模式的“适配加成”数据来自知识库的卖点卡**，不代表真实销量或市场反馈。
- **LLM 路径已用真实模型联调过，但线上未启用。** 用 DeepSeek-V4.1-Flash 实测：成功时文案质量明显好于编排器（会自己把"1600 nits 是 HDR 局部峰值，不是常态全屏亮度"这类口径写清楚）。但这个共享端点响应在 49–400 秒之间波动，且经常返回 429 并发限流，3 次里成功 1 次。魔搭网关的请求上限约 120 秒，直接返回 504，所以线上保持确定性编排器——这是可用性优先的选择，不是能力缺失。本地配 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` 即可启用，失败会自动降级并如实标注原因。
- **图片数量受知识库限制**。能确认型号的图片共 68 张，`d16` 和 `xpro` 各 2 张，低于小红书 3 张的下限，系统会提示图片不足而不是借别的机型的图。
- **合规规则是词表加启发式**，覆盖赛题五类加虚构体验、动态信息、虚假稀缺和平台规则，但不能替代人工复核。发布前仍需人工确认价格、库存、活动规则和服务条款。
- **正文里的过渡句式还在打磨**。“资料中对应的一条是：”这类引导词已经多样化（6 种轮换），读起来仍偏资料腔，这是当前最影响“软文质量”得分的地方。

## 八、Demo 视频脚本

无剪辑的连续录屏，一条主线加一次换平台。

1. **0:00-0:20** 打开首页，点右上角显示知识库抽屉（账号掩码、KB 名称、连接状态、接口返回）。

3. **1:20-2:30** 看四段结果：场景判断（策略解释）、知识库依据（事实编号、资料标题、官方链接）、图文软文（标题备选、正文、图片按位置内嵌）、核验结果（逐句、逐图、逐条合规）。
